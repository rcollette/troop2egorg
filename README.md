# Troop 2 East Greenwich demo site

This is a small, static site intended for deployment at `www.troop2eg.org/demo`.

## Editing guide

- Edit page copy and links in `dist/index.html`.
- Edit reusable visual styles in `dist/assets/css/site.css`.
- Put shared browser behavior in `dist/assets/js/site.js`.
- Place image, font, and icon files under `dist/assets/`, then reference them with relative paths.

The HTML deliberately has no embedded style or script blocks.

## Content source

The home page is based on the content selected from the public TroopWebHost page on 2026-09-13. Its ten referenced images are stored locally in `dist/assets/images/`.
